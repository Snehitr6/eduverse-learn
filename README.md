# 🎓 EDUVERSE – Online Learning Platform

**Learn. Grow. Succeed.**

EDUVERSE is a modern, responsive online learning platform built with React.js, Vite, and Tailwind CSS. It provides a user-friendly environment where students can explore courses, enroll in learning programs, watch video lessons, and track their learning journey.

## 🚀 Features

### 🏠 Home Page
- Modern and attractive landing page.
- Professional hero section with animations.
- Explore popular learning categories.
- Featured courses.
- Why Choose EDUVERSE section.
- Student testimonials.

### 📚 Courses
- Browse available courses.
- Course details and descriptions.
- Course categories and filtering.
- Course enrollment functionality.
- Online video lesson previews.

### 👨‍🎓 Student Dashboard
- Personalized student welcome section.
- View enrolled courses.
- Course progress overview.
- Recently accessed lessons section.
- Learning achievements overview.
- Recommended courses.

### 🔐 Authentication
- Student registration.
- Login and logout functionality.
- Form validation.
- Duplicate email checking.
- Persistent demo login using localStorage.

### 📱 Responsive Design
- Desktop, tablet, and mobile layouts.
- Responsive navigation menu.
- Smooth page transitions.
- Modern animations and hover effects.
- Hidden scrollbar with scrolling enabled.

### 📩 Additional Pages
- About EDUVERSE.
- Contact page.
- Login page.
- Signup page.
- Student Dashboard.

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| React.js | Frontend development |
| Vite | Development server and build tool |
| Tailwind CSS | Styling and responsive design |
| React Router DOM | Page navigation |
| Framer Motion | Animations and transitions |
| JavaScript | Application functionality |
| LocalStorage | Demo authentication and browser-side data |
